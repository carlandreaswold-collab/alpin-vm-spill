# NRK Sportens alpin-VM-spill

Et lite nettspill om alpin-VM 2027 i Crans-Montana, Sveits (1.–14. februar 2027). Fire disipliner: slalåm, storslalåm, super-G og utfor, med hopp, is og sveitsiske hindre. Styres med venstre/høyre, og pil ned (S) gir hocke i super-G og utfor. Én HTML-fil, ingen avhengigheter.

Spill det: https://alpin-vm-spillet.nrk-stash.dev/
